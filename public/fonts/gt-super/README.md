# GT Super Display — font files

GT Super is a licensed typeface from Grilli Type. The two files here are the
free **trial** fonts (Grilli-Type-Trial-Fonts-2026-04 package, requested for
zarahai.llp@gmail.com on 2026-09-27) and are covered by Grilli Type's Trial
Fonts EULA: mockups and client review only. A full web licence must be bought
before the site goes live with this face.

    GT-Super-Display-Regular.woff2
    GT-Super-Display-Regular-Italic.woff2

Trial-font limitations to keep in mind when reviewing Option 2:

- Reduced character set: A–Z, a–z, 0–9, hyphen, comma, full stop. Curly
  quotes, apostrophes, ampersands, question marks and accents are not in the
  trial files, so those glyphs fall back to Georgia inside a GT Super heading.
- No kerning or OpenType features, so letter fit is slightly looser than the
  retail font will be.

Replace both files with the licensed ones (same filenames) and nothing else
needs to change. Licence: https://www.grillitype.com/typeface/gt-super
