# GT Super Display — font files

GT Super is a licensed typeface from Grilli Type and is not included in this
repository. Drop the files here with exactly these names and the "Option 2"
pairing in the typography preview will pick them up automatically:

    GT-Super-Display-Regular.woff2
    GT-Super-Display-Regular-Italic.woff2

(.woff files with the same base names are also read as a fallback.)

For a client review, Grilli Type's free trial fonts are the right files:
https://www.grillitype.com/typeface/gt-super — trial fonts cover mockups and
presentations; a full licence is needed before the site goes live with them.

Until the files are present, Option 2 falls back to Georgia and the switcher
shows a "font files pending" note.
